# M2A writing-experience contract

This bounded increment retains 34 tools, project configuration/CAS, 17 Writer audit categories, independent 7/6 Reviewer checks, body Hash binding, one revision maximum, request idempotency, Closure and cancellation/recovery. No production plugin or existing book configuration is migrated.

## Prepare

`lengthGuidance` resolves the current project contract and config revision. Its last five committed Meta samples preserve chapter/body SHA/revision and never lower the configured target. Metrics report mean, first-to-last change and trailing consecutive chapters below target. Three consecutive below-target chapters warn; at least three strictly descending consecutive samples with a net decline of 10% of the configured target warn. These transparent heuristics do not reject a legal 2000-character chapter or prove a model-generated shortening cause.

Writer and Reader receive up to three field-projected committed signatures; future/uncommitted/stale Hash entries are omitted with source diagnostics. They receive signatures with chapter/body SHA; optional opening/solution/stage fields remain compatible with old books. Fatigue accepts Engine entries/arrays/JSONL and sorts chapter/chapterNo before choosing its window. All warnings remain non-blocking; callbacks and deepening investigations are legitimate.

Optional `stage-plan` uses `novel-stage-plan-v1`; details and limits are in [stage-growth](../workspace-novel-author/skills/novel-author/protocols/stage-growth.md). Prepare separates planned ranges, Hash-bound observed stage and missing/unresolved ledger evidence. It includes relevant previous-stage debts/costs and sources, without automatically changing world state or treating a plan as a paid payoff.

Prepare's bounded dependency fingerprint includes consumed config/state, blueprint, stage, ledgers/state/memory, recent Summary/Delta/Meta and previous body. Explicit bounded stage references may add older Meta identities. Bigint file identity includes missing marker, dev/ino/size/mtimeNs/ctimeNs, allowing independent Engine writes to invalidate cache. Concurrent fast cold roles share an in-flight assembly in the existing bounded cache. Cold assembly verifies its sources and retries at most once; a second change returns `PREPARE_CONTEXT_CHANGED`. This is not a globally atomic project snapshot or a whole-book semantic retrieval system.

Writer/Continuity/Reader packets retain 16000/8000/6000 character caps in fast and compact. Required outline, resolved specs, Writer audit contract, stage IDs/Hashes and signatures are not tail-clipped. Excess required material returns `PREPARE_REQUIRED_CONTEXT_BUDGET_EXCEEDED`; optional section omissions appear in `packetDiagnostics` and require narrow queries when relevant. Full remains a diagnosis-only view, not an additional prompt attachment.

## Default production path

Preflight → three actual role Prepare responses saved before Writer (fast cold1/hot2, same key) → one Writer with body+audit → local handoff/length → two independent parallel Reviewers using saved packets → local Quality/Precommit → one Finalize → checkpoint/report. Finalize persists Audit and Quality internally; local receipts are not Engine success. Fallback only when Finalize is unavailable records real Audit, Quality, Commit and complete Closure/Integrity. Schema/network failures correct/reconcile payload, not repeat semantic generation. Expired same-key reconstruction is truthfully `reused=false`.

## Limits

Local Python adds `preferredTargetRangePass`, `belowPreferredTarget` and warnings while retaining legacy `targetRangePass`, acceptance and hard-gate behavior. Python's BMP Han range and Engine's Unicode Script=Han still differ for extension characters: confirmed and explicitly out of this bounded increment, not fixed. Historical YAML/runtime state naming is also not rebuilt here.

Synthetic behavior tests and packet character counts do not establish literary quality, real provider tokens/cost, latency improvements, ten-chapter generated length stability or actual Gateway orchestration. No paid generation, new supplier, database, UI or production deployment was performed.
