# 公开发布与隐私边界

## 仓库包含

- 两个 Agent 的通用编排规则；
- 9 个 DeepWhite Skills；
- 确定性 Gate、模板和测试；
- 安装器与配置示例。

## 仓库不包含

- `projects/` 中的小说正文、分集规划和生产结果；
- `memory/`、`DREAMS.md`、`MEMORY.md`、会话和学习记录；
- n8n Workflow 凭证、Webhook 密钥、模型 API Key；
- 作者 NAS 的绝对路径、IP、项目名和历史调试脚本；
- 图片、视频、Base64 或最终 MP4。

安装与更新只复制公共模板。已有同名文件会先备份；运行数据目录不参与复制。
