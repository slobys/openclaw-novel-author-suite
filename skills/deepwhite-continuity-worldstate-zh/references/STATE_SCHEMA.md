# 世界状态字段规范

## 三层状态

### 固定设定
角色身份、年龄段、稳定外貌、基础服装设计、场景建筑结构、关键道具造型。除非剧情明确改变，不得变化。

### 当前状态
位置、朝向、姿态、持物、衣服湿度、伤痕、污渍、门窗开合、灯光强弱、天气、道具数量等。必须从上一镜继承。

### 本镜变化
只有本镜动作真正造成的变化。每项变化必须写触发动作和变化后的结果。

## 镜尾原则
镜尾状态必须精确到可以直接作为下一镜第一帧：人物身体位置、手部、视线、动作阶段、道具接触点和环境变化都要写清。
