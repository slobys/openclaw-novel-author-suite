# 国内 AI 漫剧专业改编规范

本规范用于把小说事件转换为适合短视频平台观看、同时保留原著逻辑和人物厚度的系列漫剧。它是专业判断框架，不是热门题材复制器。

## 1. 系列定位卡

规划前必须生成 `plan/format_strategy.json`，至少回答：

- `format_profile`：`auto | domestic_vertical_manga | cinematic_horizontal`
- `genre_profile`：`growth_reversal | emotional_relationship | suspense_mystery | comedy_absurd | ensemble_reality | hybrid`
- 核心受众、观看场景与内容分级
- 原著卖点、情绪承诺和不可牺牲的核心
- 单集时长、画幅、季集数及选择理由
- 主要故事引擎、回报类型、追更理由
- 视觉格调、色彩、线条/材质、动效强度和表演尺度
- 模型生产风险、资产复用策略与成本上限

用户明确指定画幅、时长、风格或平台时，以用户要求为准。

## 2. 题材与故事引擎

### 成长/逆袭

核心不是反复羞辱与打脸，而是“目标—阻碍—选择—代价—能力/资源/身份升级”。每次回报必须带来新问题，避免原地循环。

### 情感/关系

用可见选择体现情感：谁相信谁、谁保护谁、谁拒绝谁、谁掌握关系定义权。误会必须有信息基础，不能靠角色突然降智维持。

### 悬疑/推理

每集至少推进证据、认知或嫌疑结构中的一项。真相揭示必须能回溯到已出现线索，避免结尾空降设定。

### 喜剧/沙雕

优先使用设定冲突、行为反差、误会升级、视觉回环和角色性格产生笑点。网络梗只能点到为止，不能替代人物和故事。

### 群像/现实

每集明确主视角和主冲突，其他人物只保留会改变主线结果的行动。现实议题以人物选择和后果呈现，避免口号式说教。

## 3. 单集节奏合同

节奏按“功能”而不是机械秒表切割。对 60–180 秒竖屏漫剧，默认参考：

| 区间 | 必须完成的功能 |
|---|---|
| 0–3 秒 | 用异常结果、迫近危险、身份反差、关键承诺或未完成动作建立注意力 |
| 3–15 秒 | 明确本集人物目标、冲突双方和失败代价 |
| 中段 | 每 10–20 秒发生一次有效变化：新信息、关系变化、局势升级、选择或回报 |
| 末段前 | 给出本集承诺的一次实际回报，不能只铺垫不兑现 |
| 最后 3–8 秒 | 形成具体未完成动作、揭示、选择、危险或代价，驱动下一集 |

横屏影视化模式允许更长建立，但每一场仍必须发生价值变化。

### 有效节拍判定

一个节拍只有改变以下至少一项才算有效：

- 人物目标或决策；
- 权力、关系或情绪地位；
- 观众掌握的信息；
- 风险、代价或时间压力；
- 可使用的资源、能力或证据；
- 物理位置、持物权或连续性状态。

单纯换景、重复解释、不同人物复述同一事实不算新节拍。

## 4. 情绪与回报设计

每集建立 `emotion_curve`，至少包含起始情绪、压力上升、反转、主要回报和结尾残留情绪。情绪必须由事件触发，并通过表情、动作、关系、空间或声音表现。

`payoff_map` 中区分：

- `micro`：小信息、小胜利、小笑点或小关系变化；
- `primary`：兑现本集主承诺；
- `series`：推动季级目标、身份或真相。

60–90 秒单集通常至少需要 1 个主要回报；120–180 秒可增加 1–2 个微回报。数量不是硬指标，重复同类回报不计数。

## 5. 视觉漫剧化

### 先动作后解释

把抽象叙述转换为：

- 人物在做什么；
- 关键物件如何出现或转移；
- 空间距离和站位如何表达关系；
- 哪个表情、手势、目光或声音承担信息；
- 镜头前后世界状态发生了什么变化。

### 竖屏构图

- 优先 1–3 人清晰关系，避免无必要的大群像；
- 主体占屏明确，使用前中后景形成深度；
- 关键道具和表情必须在手机屏幕上可读；
- 对话场不连续使用同一平视半身构图；
- 重要反转用视线、遮挡、物件、距离或动作揭示，不只靠字幕。

### 资产与生成成本

- 复用核心人物、常驻服装、主场景和标志性道具；
- 新资产必须对剧情、识别度或跨集连续性有明确价值；
- 状态变化用 `base_asset_id + state_version` 表示；
- 场景能合并则合并，但不能破坏空间逻辑；
- 对群体打斗、复杂手部交互、多人同步、液体、变形和大范围破坏标记高风险并拆解。

## 6. 格调与内容质量

流行不等于低俗。禁止用以下内容作为唯一观看动力：

- 无因果的连续羞辱、极端猎奇或恶意标签；
- 角色突然降智以制造误会；
- 女性、老人、儿童或弱势群体的工具化伤害；
- 只靠旁白宣称“很强、很爱、很惨”，画面没有证据；
- 机械堆梗、过时网络梗和与世界观不符的台词；
- 为卡点强行截断完整动作或情绪。

专业格调来自统一的语言尺度、表演尺度、视觉材质、色彩、声音和价值立场。

## 7. 专业 Gate

每集写入 `professional_gate`，评分均为 0–100：

| 维度 | 核心问题 |
|---|---|
| source_fidelity | 事件、动机、因果是否可回溯，是否误改原著核心 |
| hook_clarity | 目标观众能否迅速理解为什么要继续看 |
| conflict_progression | 冲突是否升级而非重复 |
| emotion_payoff | 情绪是否有铺垫、变化和回报 |
| character_integrity | 人物是否按动机行动而非工具化 |
| visual_storytelling | 关键信息能否由画面和动作承担 |
| continuity_safety | 人物、时间、道具、空间和伏笔是否一致 |
| production_feasibility | 是否可由当前图片/视频模型稳定生成 |
| asset_efficiency | 新资产成本是否合理、复用是否充分 |
| ending_pull | 结尾是否形成具体追更动力 |

通过条件：

- 总分 `overall_score >= 82`；
- `source_fidelity`、`character_integrity`、`continuity_safety` 均不低于 80；
- `hard_failures` 为空；
- 有证据、有问题记录、有具体修复动作。

硬失败包括：来源不可追溯、关键人物动机反转无依据、核心因果断裂、剧透锁失效、连续性冲突、没有开场钩子、没有本集回报、结尾没有追更动力、生产上无法实现且未拆解。

## 8. 质量优先的趋势使用原则

- 趋势数据只帮助选择表达方式、时长、画幅和宣发卖点；
- 不把某个热门题材强加给不匹配的原著；
- 不把“爽点密度”误解为每十秒打脸；
- 不以点击率逻辑牺牲人物动机、因果和长期追更价值；
- 每季度或平台策略变化后可更新定位画像，但历史项目继续使用已冻结的 `format_strategy.json`。
