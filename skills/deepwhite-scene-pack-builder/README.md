# deepwhite-scene-pack-builder v3.2.0

本版本新增 **人物 / 动物 / 生物 / 道具连续资产模式**，并引入新的默认比例逻辑：

- **场景类默认：16:9 横版**
- **人物 / 动物 / 生物 / 道具类默认：9:16 竖版**

同时保留：
- 零配置启动
- PORTABLE HARD LOCK
- 中文输出
- 逐张输出
- 场景位置直出
- 资产队列 / 指定跳转 / 重做版本

## 最简调用示例

### 场景
```text
新建一套现代中国室内连续场景资产
```

### 人物
```text
新建一套农民老伯人物多角度资产
```

### 动物
```text
新建一套橘猫动物多角度资产
```

### 生物
```text
新建一套异兽生物多角度资产
```

### 道具
```text
新建一套青铜长剑道具多角度资产
```

## 各模式默认第一张资产
- 场景室外：L01
- 场景室内：F01
- 人物：C01
- 动物：A01

## v3.1.0 人物指定直出

人物资产建立后，可以直接输入：

```text
输出正面
输出左侧面
输出右侧面
输出背面
输出头部特写
输出正面全身
输出左侧面半身
输出正面惊讶表情头部特写
```

系统会生成 `CPxx` 单张资产，例如：

```text
CH001-ST01-CP01-v001｜正面全身标准视图
CH001-ST01-CP02-v001｜左侧面全身视图
CH001-ST01-CP03-v001｜正面头部特写
```

查看可调用视图：

```text
列出当前人物可调用视图
```


## v3.2.0 角色锚点链模式

现在支持把你当前上传的人物图作为锚点来派生其他人物视图。

### 常用调用
```text
以当前上传的人物正面全身图为主参考，输出左侧面全身
以当前上传的人物正面全身图为主参考，输出背面全身
以当前上传的人物正面全身图为主参考，输出头部特写
用当前上传图片建立角色锚点
列出当前角色锚点
```

### 锚点类型
- Anchor-A：主身份锚点（通常为正面全身）
- Anchor-B：脸部锚点（通常为头部特写）
- Anchor-C：相邻视角锚点
- Anchor-D：动作 / 道具锚点

### 评级
每次派生人物图时，技能应给出：
```text
REFERENCE COVERAGE：GREEN / YELLOW / RED
```
并附上“下一步建议补充”。
