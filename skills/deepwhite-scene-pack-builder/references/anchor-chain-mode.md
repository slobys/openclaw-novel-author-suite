# 角色锚点链模式

## 目标
利用当前上传人物图或已通过人物资产，建立连续参考链，减少逐张生成人物时的身份漂移。

## 锚点类型
- Anchor-A：主身份锚点
- Anchor-B：脸部锚点
- Anchor-C：相邻视角锚点
- Anchor-D：动作/道具锚点

## 典型调用
```text
以当前上传的人物图为主参考，输出左侧面全身
以当前上传的人物正面图为参考，输出背面全身
以当前上传的人物图为主参考，输出头部特写
列出当前角色锚点
```

## 输出要求
- 必须说明当前上传图被注册为什么锚点
- 必须输出 REFERENCE COVERAGE
- 必须给出下一步建议补充
