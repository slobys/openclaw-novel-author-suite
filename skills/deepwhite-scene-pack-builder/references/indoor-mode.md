# 室内模式参考

## 适用场景
客厅、卧室、书房、办公室、会议室、教室、客栈内部、别墅一层公共区等。

## 关键锁定项
1. Room Topology：房间轮廓、长宽比例、挑空/层高
2. Door/Window Layout：门、窗、阳台门位置与朝向
3. Furniture Anchors：沙发、茶几、电视墙、床、桌椅、岛台、楼梯等
4. Room Connectivity：通往餐厅、走廊、楼梯、书房、阳台的连接方式
5. Material Logic：地面、墙面、天花、木饰面、石材、玻璃
6. Lighting Logic：自然光方向、主灯具位置、昼夜状态
7. Occlusion Logic：哪面墙遮挡什么，不强行“全看见”

## 室内标准机位建议
- V01：入口看主空间
- V02：主空间看主视觉面（如电视墙 / 床头墙）
- V03：反向回看入口与主要家具
- V04：楼梯口 / 走廊口斜看主空间
- V05：窗边 / 阳台门边回看室内
- V06：高位总结机位

## 室内自定义机位 CV 提示
用户指定：
- 相对于哪件家具或门窗的位置
- 摄影机高度
- 面向哪个目标
- 想看到哪些元素
- 哪些本来应被遮挡
