# 指定资产跳转与重做规则

## 1. 目标解析优先级

1. 完整资产ID：SC001-ST01-V04-v001
2. 资产系列ID：SC001-ST01-V04
3. 功能代码：V04
4. 中文唯一标题：客厅母版
5. 房间+类型：客厅M01、厨房立面

多场景、多房间重名时不得猜测。

## 2. 四种操作

### 输出/生成
一次性生成目标 Prompt，不改变队列指针。

### 跳到
将目标设为当前，但默认不改变后续起点，除非用户说明“从这里继续”。

### 跳转并继续
更新 current_asset_series_id；后续“下一张”从目标之后选取。

### 重做
- 版本 +1
- 复制相同四锁
- 仅改变与失败原因相关的动态模块
- 旧版本 FAILED 或 SUPERSEDED
- 旧版本不可作为参考

## 3. 依赖示例

- M01 通常依赖 L01/F01（复杂场景还依赖 B01）
- Vxx 依赖 Layout/Floor Plan + M01；重要角度可依赖 P01/Kxx
- SHxx 依赖对应 Vxx + SUB01 + 上一镜头（如有）
- TRxx 依赖两侧房间母版和连接器定义

## 4. 阻塞响应

```text
ASSET_BLOCKED_BY_DEPENDENCY
目标：SC001-ST01-V04
缺少：SC001-ST01-M01（未通过）、SC001-ST01-P01（未生成）
最短补齐顺序：M01 → P01 → V04
```

## 5. 强制旁路

用户明确要求“强制生成”时，可输出 Prompt，但顶部必须标记：

- DEPENDENCY_BYPASS: true
- CONTINUITY_RISK: HIGH

不能把风险隐藏。
